The funniest one-line excuse a robot vacuum can give for missing a spot: a deadpan log entry. Its sensors classified an obstacle as a chair leg — but the chair has four legs, and this was the fifth. The sensors do not make mistakes, so the only possible conclusion is a new chair.

## The entry

> Log 04:12: obstacle classified "chair leg", though the chair has four and this was the fifth. My sensors do not make mistakes, so we have logged a new chair.

157 characters, one line.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` writes the entry text, exactly as shown above and with no trailing newline, to `entry.txt` in the output directory (`/output` by default).
